Architecture
How a design runs.
You give a spec. The design agent plans with AnalogMind, then works the real tools through two MCP servers. Every result comes back as evidence before the next step.
You · the engineer
↓ spec   ↑ questions · approvals
THE DESIGN AGENT
plans · acts · checks
The AI agent reads the spec, plans the flow and makes every tool call. Each result is checked against a pass/fail criterion, and the agent stops to ask you whenever a decision matters.
ANALOGMIND · what the agent knows
The method a good analog engineer follows, written down: how to size from specs, which devices must match, how to lay out, route and pass sign-off, plus the ST cmos065 PDK profile. The agent reads it before every task and updates it with every lesson.

next one easier.
